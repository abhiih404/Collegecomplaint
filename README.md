# 🎓 College Complaint Registration System

A web app where students can register complaints and track whether they are Pending or Resolved.

🔗 **Live demo:** https://abhiih404.github.io/Collegecomplaint/

## Screenshots
![Login]
![Complaint form]
![Complaints table]

## Features
- Login page
- Complaint submission form
- Table view of all complaints
- Toggle status between Pending and Resolved
- Data saved in the browser using LocalStorage

## Tech Stack
HTML5, CSS3, JavaScript (LocalStorage)

## How to Run Locally
1. Download or clone this repository
2. Open `index.html` in your browser

## Known Limitations
- Login is a demo and does not verify real accounts
- Data is stored only in your own browser
